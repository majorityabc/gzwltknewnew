# 2026-05-03 开发对话记录

## 项目概述

高中物理题库收集分类系统。上传 .docx 试卷 → 原样显示公式和图片 → 分割题目 → 打标签 → 编辑内容。

技术栈：Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + TipTap + KaTeX + Prisma + SQLite

## 本次解决的问题

### 1. .docx 上传后页面无显示

**原因**：`fast-xml-parser` 的 `preserveOrder: true` 输出格式中，`result[0]` 是 `<?xml?>` 声明而非 `<document>` 元素，导致找不到文档根节点。同时 `textOf()` 函数无法提取嵌套文本。

**修复**：
- `src/lib/docx-parser.ts`：遍历 result 数组找到 `tagName === "document"` 的元素
- `textOf()`：递归提取子节点中的 `#text`

### 2. 图片提取

**嵌入图片**（`wp:inline`）：原生支持
**环绕图片**（`wp:anchor`）：新增支持

**关键修改** (`src/lib/docx-parser.ts`)：
- 新增 `ImageRun` 类型（`type: "image", src, alt, width, height`）
- 新增 `parseRelationships()` — 解析 `word/_rels/document.xml.rels`，构建 rId → zip路径映射
- 新增 `extractDrawingImage()` / `extractPictImage()` / `getImageRun()` — 提取图片并转为 base64 data URL
- 图片可能嵌套在 `<w:r>` 内，且可能被 `<mc:AlternateContent>` 包裹，使用 `findDescendant()` 递归深搜
- 同时处理 `wp:inline`（嵌入式）和 `wp:anchor`（环绕式）

### 3. 排版优化

- 预览区和题目卡片区段落间距增大（`mb-1` → `mb-2`，`px-4 py-2` → `px-5 py-3`）
- 选项段落（A/B/C/D 开头）自动缩进 + 上方留白

### 4. 题目可编辑

**新增文件**：`src/lib/tip-tap-converter.ts` — 将 `DocParagraph[]` 转换为 TipTap ProseMirror JSON 格式

映射规则：
| DocParagraph/ParagraphRun | TipTap JSON |
|---|---|
| `TextRun { text, bold, italic, underline }` | `{ type: "text", text, marks: [...] }` |
| `FormulaRun { latex }` | `{ type: "inlineMath", attrs: { text: latex } }` |
| `ImageRun { src, alt }` | `{ type: "image", attrs: { src, alt } }` |
| `DocParagraph { style: "Heading1" }` | `{ type: "heading", attrs: { level: 1 } }` |
| `DocParagraph { style: 空 }` | `{ type: "paragraph" }` |

**修改**：`src/app/upload/page.tsx` — 题目卡片中用 `<RichTextEditor>`（`next/dynamic` 动态加载，`ssr: false`）替代只读 `<RenderRun>`。

### 5. 页面布局改为左右双栏

分割后布局：
- **左侧（w-1/2）**：题目卡片（TipTap 可编辑）
- **右侧（w-1/2）**：紧凑预览 + 分割控制 + "重新分割"按钮

## 关键文件当前状态

### `src/lib/docx-parser.ts`
- .docx 解析核心
- `parseDocx(buffer)` 主入口
- `extractParagraph(pEl, imageMap, zip)` 段落提取
- `parseRelationships(zip)` 图片关系映射
- `findDescendant(el, tag)` 递归深搜
- 输出类型：`DocContent { paragraphs: DocParagraph[] }`
- `DocParagraph { runs: ParagraphRun[], style?: string }`
- `ParagraphRun = TextRun | FormulaRun | ImageRun`

### `src/lib/omml-to-latex.ts`
- OMML → LaTeX 转换
- 支持：分式、根号、上下标、重音、括号、求和/积分、矩阵

### `src/lib/tip-tap-converter.ts`
- `docParagraphsToTipTapJson(paragraphs: DocParagraph[]): object`
- 将解析结果转为 TipTap JSON 格式

### `src/app/upload/page.tsx`
- 上传页面（三阶段：上传 → 分割 → 编辑+打标签）
- 动态导入 `RichTextEditor`（`ssr: false`）
- 分割后左右双栏布局

### `src/components/tiptap/rich-text-editor.tsx`
- TipTap 富文本编辑器
- 扩展：StarterKit + Superscript + Subscript + Underline + ImageExt + InlineMath
- 粘贴清理（Word HTML → 纯内容）
- 公式图片占位 → 点击输入 LaTeX

### `src/components/tiptap/math-extension.ts`
- 自定义 `inlineMath` 节点（atom, inline）
- 属性：`text`（LaTeX 源码）

### `src/app/api/parse-docx/route.ts`
- POST 接口，接收 .docx 文件，返回 `{ content: DocContent }`

## OMML → LaTeX 支持的公式类型

| OMML 元素 | LaTeX 输出 | 示例 |
|---|---|---|
| `m:f` | `\frac{num}{den}` | 分式 |
| `m:rad` | `\sqrt[n]{e}` | 根号 |
| `m:sSup` | `base^{sup}` | 上标 |
| `m:sSub` | `base_{sub}` | 下标 |
| `m:sSubSup` | `base_{sub}^{sup}` | 上下标 |
| `m:acc` | `\hat{e}`, `\vec{e}`, `\dot{e}` 等 | 重音符号 |
| `m:bar` | `\overline{e}` / `\underline{e}` | 上下划线 |
| `m:d` | `\left( e \right)` | 括号 |
| `m:nary` | `\sum_{sub}^{sup}{e}` | 求和/积分 |
| `m:eqArr` | 多行公式 | 方程组 |
